# Application INV

Aplicación web desarrollada en Python con FastAPI para la gestión e inversión de datos financieros, análisis con Pandas y Morningstar (`mstarpy`), e interfaz frontend integrada.

## 🚀 Características

* **Backend:** API REST de alto rendimiento con FastAPI y Uvicorn.
* **Finanzas & Datos:** Integración con `mstarpy` y `pandas` para análisis de fondos y datos financieros desde archivos Excel (`Fondos.xlsx`).
* **Frontend:** Interfaz alojada en la carpeta `/frontend`.
* **Contenedores:** Despliegue listo para Docker y Docker Compose.

---

## 🛠️ Requisitos Previos

* **Python 3.10+** (para ejecución local)
* **Docker y Docker Compose** (para despliegue en contenedor)
